# Move All Zeros to the End in C

## Problem

Given an array containing positive, negative, and zero values, move all zeros to the end while maintaining the relative order of non-zero elements.

## Example

Input: `0 1 0 3 12`

Output: `1 3 12 0 0`

## Concepts Used

* Arrays
* Loops
* Conditional statements
* In-place array modification

## Approach

Traverse the array and move every non-zero element to the front. Fill the remaining positions with zeros.

## Complexity

* Time Complexity: O(n)
* Auxiliary Space Complexity: O(1)

## Language

C
